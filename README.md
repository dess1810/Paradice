# Nombre del proyecto: agencia paradice
Proyecto para la agencia de viajes paradice gestiona usuarios viajes nacionales e internacionales 

# Objetivo
Desarrollar una app web para la agencia de viajes paradice en un periodo de 4 mesee con la metodologia scrum y html, css, js y sql

# Funcionalidades 
-[ ] Gesiton de usuarios
-[ ] Gesiton de viajes nacionales 
-[ ] Gesiton de viajes internacionales 
-[ ] Gesiton de turs 
-[ ] Gesiton de reportes
